# ADR 0008: Архитектура фронтенда (React + Vite SPA)

**Дата:** 2025-10-02
**Решение:** Зафиксировано реализованное архитектурное решение фронтенда — **один React SPA** на Vite без SSR, UI-kit и React Query (Day 1).

**Почему:**

* Простая SPA-архитектура полностью покрывает MVP-функциональность.
* Разделение API и SPA в Dev-режиме обеспечивает удобную разработку и отладку.
* В Prod-режиме единый домен для API и фронтенда упрощает деплой и исключает проблемы CORS.

**Следствие:**

* В продакшене собранный SPA (`frontend/dist`) обслуживается ASP.NET Core через `wwwroot`.
* Настроен **SPA fallback** (`MapFallbackToFile("index.html")`) для маршрутов React.
* В Dev-режиме фронтенд и API работают на отдельных портах (5173 / 5000), с разрешённым CORS.
* В `Program.cs` реализован порядок middleware, обеспечивающий корректное разделение `/api/*` и маршрутов SPA.
