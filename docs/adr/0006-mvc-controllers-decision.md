# ADR 0006: Переход на MVC

**Дата:** 2025-09-26  
**Решение:** Мы меняем архитектуру контроллеров проекта на **MVC-подход**.  

**Почему:**  
- Минимальный API перестаёт быть удобным при росте числа конечных точек.  
- MVC обеспечивает лучшую структурированность и читаемость.  
- Легче подключать фильтры (например, ExceptionFilter для централизованной обработки).  

**Следствие:**  
- Контроллеры и действия вынесены в отдельные классы.  
- Настроены конечные точки на созданные контроллеры.  
- В кодовой базе закрепляется MVC как базовый стиль разработки API.
