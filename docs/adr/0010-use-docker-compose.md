# ADR 0010: use-docker-compose

**Дата:** 2025-10-11  

## Решение
Использовать **Docker Compose** для локального и серверного развертывания связки  
**backend (ASP.NET API)** + **PostgreSQL**.  

- **PostgreSQL** — всегда в контейнере.  
- **Backend** может запускаться как в контейнере, так и напрямую на хосте.  
- Внутренняя сеть контейнера — API и БД могут общаться через неё.  
- Volume `pgdata` обеспечивает сохранность данных БД.  
- Переменная подключения `ConnectionStrings__Default` различается для контейнера и хоста.  

## Почему
- Не нужно настраивать БД локально.  
- Единообразие конфигурации Dev/Prod и CI.  

## Следствие
- API и БД изолированы в контейнерах, но могут работать независимо.  
- База данных сохраняет состояние между перезапусками.  
- Backend может запускаться как локально, так и в Docker, без изменения кода или конфигурации приложения.
